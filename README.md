Google Chrome on linux password check
===========

Small claude generated python script to check whether passwords in google chrome based browsers on linux are properly encrypted or not  
If not, it will paste every entry in the password manager inside the shell  

## How to use

Install google chrome and add an entry to the password manager  

Clone repository, install python if not installed already.  
Then, change directory into project and create and activate a virtual environment with:  

```
python3 -m venv .venv
source venv/bin/activate
```

Then, install dependency with  
```
pip install pycryptodome
```
or  
```
pip install -r requirements.txt
```

Then run it with:  
```
python test.py
```
If password entry shows up: 😬  


## Explanation

On Windows, DPAPI (Data Protection Application Programming Interface) is used by Edge and Chrome to encrypt passwordfiles properly  
On Linux however, Chrome support Gnome Keyring and Kwallet (KDE), both relying on libsecret.  
If neither are supplied (when either Gnome keyring is removed or KWallet is disabled/removed), Chrome's encryption process becomes predictable.  

Chrome encrypts it's passwordfile with AES-128-CBC. This functions needs a proper key, which is generated by PBKDF2 (Password Based Key Derivation Function 2).  
PBKDF2 is used to get a key with a fixed length. It does by hashing (using SHA1 in this example) the password + salt the first time, then hashing the password again but using the result as from the first hash as the salt for second time. It does this process a few times and then adds (or XOR's) all off the results together to get a fixed length key.  
The problem however, is that when google chrome doesn't know what keyring to use, it defaults to <mark>'peanuts' for the password and 'saltysalt' for the salt. So make sure either are installed and available when using chrome</mark>  


For KDE specifically, make sure KWallet isn't disabled (as it allows you to do so) when using chrome's password manager.  
You can force a prompt to check whether it works properly with  
```
google-chrome-stable --password-store=kwallet
```
On other desktop environments, try this:  

```
google-chrome-stable --password-store=gnome
```
(This includes non-gnome environments like XFCE)
